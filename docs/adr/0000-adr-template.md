# ADR NNNN — Short decision title

- Status: proposed | accepted | superseded by ADR NNNN
- Date: YYYY-MM-DD

## Context

The forces that make a decision necessary: the constraint, the failure that keeps happening, or the fork in the road. Facts only — no solution here. If a reader disagrees with this section, they will disagree with the decision, and that is the useful conversation.

## Decision

What was decided, in the present tense and specific enough to check a diff against. Name the concrete surfaces it binds: modules, contracts, commands, files.

If the decision has a trigger for revisiting it, state the trigger as a condition, not a date.

## Consequences

What becomes easier, what becomes harder, and what is now required of everyone. Include the costs you accepted — an ADR listing only benefits is advocacy, not a record.

## Alternatives considered

Each option a reasonable engineer would have chosen, and the specific reason it lost. Omit this section only when there genuinely was no alternative.
