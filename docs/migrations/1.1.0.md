# Migrate base 1.0.0 → 1.1.0

## App identity

1. Copy `config/brand.example.json` ra file cấu hình riêng.
2. Điền name, slug, scheme, iOS bundle ID và Android package.
3. Chạy dry-run, kiểm tra danh sách target rồi chạy initializer.
4. Đặt `EXPO_PROJECT_ID` riêng trong EAS environment của dự án.
5. Không tái sử dụng project ID hoặc application ID của base 1.0.0.

## Environment

Tạo `.env.local` từ `.env.example`. `EXPO_PUBLIC_*` được bundle vào app nên không chứa secret. Đồng bộ `APP_VARIANT` với `EXPO_PUBLIC_APP_ENV`.

## Networking

Feature không còn được phụ thuộc `AxiosError`. Chuyển mọi status/error branching sang `ApiError.kind`, `status`, `retryable` và `fields`.

Backend-specific refresh được inject qua `AppProviders.refreshAccessToken`. Nếu không cung cấp callback, authenticated 401 sẽ clear session ngay.

## Cold start

Không thêm lại `return null` trước root layout. Session hydration phải nằm trong lightweight boot state để native splash được hide sau first layout.
